# Search Vector Agent Patterns

These patterns guide agent interpretation after the compiler returns a raw
lineage. They are not compiler seeds and must not affect random selection.

## Positive patterns

- High-pain, low-complexity problems
- Rare but important events
- Low-frequency obligations with expensive consequences
- Information fragmented across chats, photos, email, spreadsheets, or notebooks
- Narrow workflows hidden inside broad platforms
- Preserving history, evidence, service records, and family knowledge
- Calm software that performs one job well
- Medium-frequency pain or low-frequency high-consequence work
- Existing small competitors whose users complain about complexity or missing focus

## Anti-patterns

- A feature pretending to be a product
- Absence of competitors interpreted as opportunity
- Chasing keywords instead of pain
- Crowded recent entrants
- Overbuilt solutions
- Products solving too many jobs
- Products requiring daily engagement without daily value
